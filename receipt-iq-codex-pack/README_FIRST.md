# RECEIPT IQ — Codex starter pack

1. Create/open a project directory in your coding environment.
2. Put the `design/reference.png` image in that project at that exact path.
3. Copy the contents of `CODEX_MASTER_PROMPT.md` into your Codex agent, or tell Codex: "Read CODEX_MASTER_PROMPT.md and implement it end-to-end. Inspect design/reference.png first."
4. Let Codex work through the build, run tests, and show screenshots. Make sure it distinguishes live financial calculations from demo fixtures.

This pack contains a project-building prompt and the user's supplied UI reference, not a finished web application.
